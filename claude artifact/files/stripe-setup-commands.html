Stripe Store Setup

◈ Run these commands in your terminal · Then plug the payment links into your store
Step 1 — Create Products & Prices
Run these one at a time. Each command returns a price ID (looks like price_1ABC...). Copy each one — you'll need them for the payment links in Step 2.
Product 1 — Single Song Download ($2)
Create product
stripe products create --name="Squaawke Song Download" --description="Single track digital download — AI Coin Manifesto Series" --url="https://soundcloud.com/squaawke"
click to copy
Create price (copy the product ID from above and replace prod_XXXXX)
stripe prices create --unit-amount=200 --currency=usd --product=prod_XXXXX --nickname="Single Song $2"
click to copy

Step 2 — Create Payment Links
Replace each price_XXXXX with the actual price IDs you got from Step 1. Each command returns a payment URL you can embed anywhere.
Single song payment link
stripe payment_links create --line-items[0][price]=price_XXXXX --line-items[0][quantity]=1
click to copy
Album payment link
stripe payment_links create --line-items[0][price]=price_XXXXX --line-items[0][quantity]=1
click to copy
T-shirt payment link (with adjustable quantity for size selection — customer picks qty, you confirm size via email)
stripe payment_links create --line-items[0][price]=price_XXXXX --line-items[0][quantity]=1 --line-items[0][adjustable-quantity][enabled]=true
click to copy
Each payment link looks like: https://buy.stripe.com/XXXXXXXX — paste those into the store page I'm building for you, and you're live.
Step 3 — Set Up Webhook for Download Delivery
For digital downloads, you need a way to deliver the files after payment. Simplest option for now: Stripe sends you an email notification, you manually email the download. Later we can automate this. Run this to enable email notifications:
Listen for payment events locally (for testing)
stripe listen --forward-to localhost:3000/webhook
click to copy
For now: Go to dashboard.stripe.com → Settings → Emails and enable "Successful payment" notifications. Stripe will email you every time someone pays — you reply with the download link. Simple and immediate.
